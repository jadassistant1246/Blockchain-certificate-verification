# Blockchain Certificate Verification System

A blockchain-based digital certificate verification system that uses smart contracts, cryptographic hashing, and QR codes to securely issue, verify, and detect tampered certificates.

## 📌 Project Overview

Fake and tampered educational certificates are a major problem during recruitment and document verification.

This project provides a decentralized certificate verification system where educational institutions can issue digital certificates and store their unique cryptographic hash on a blockchain.

When a certificate is submitted for verification, the system generates its hash and compares it with the hash stored on the blockchain. If both hashes match, the certificate is considered valid. If they do not match, the certificate may have been modified.
